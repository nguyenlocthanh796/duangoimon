# OngChu POS Downloads Directory

Thư mục lưu trữ các bản phát hành phân phối đa nền tảng cho hệ thống POS OngChu (https://ongchu.cloud):

1. **Android APK**: `ongchu-pos-release.apk` (Tương thích Android 7.0+, Tablet, Điện thoại, Máy POS cầm tay Sunmi / iMin).
2. **Apple iOS / iPadOS IPA**: `ongchu-pos-release.ipa` (Tương thích iOS 14.0+ / iPadOS 14.0+ cho Sideloadly / TrollStore / AltStore / MDM).
3. **Apple iOS Manifest**: `manifest.plist` (Phục vụ cài đặt In-House OTA qua giao thức `itms-services://`).
4. **Desktop Windows**: `ongchu-pos-desktop.exe` (Bản Windows Native Desktop siêu nhẹ ~12MB).
5. **Version API**: `version.json` (Cung cấp metadata phiên bản cho ứng dụng tự kiểm tra và cập nhật).
